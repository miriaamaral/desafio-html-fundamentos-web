📊 Criando Tabelas com HTML

E aí, meu 🐙! Organizar dados numéricos e textuais de forma tabular e acessível é uma arte. Veja o que aprendi sobre as Tabelas!

A Anatomia da Tabela

Para construir a malha da tabela, usamos algumas tags fundamentais. Tudo é envolvido pela tag <table>. Por dentro, usamos:

  • <tr> (Table Row): Cria as linhas horizontais.
  • <th> (Table Heading): Usado para os títulos das colunas. O texto já fica em negrito e centralizado por padrão.
  • <td> (Table Data): As células normais onde os dados moram.

Semântica Importa!

Hoje em dia não jogamos as linhas de qualquer jeito. Devemos dividir a tabela em três blocos lógicos: <thead> (cabeçalho), <tbody> (corpo com os dados) e <tfoot> (rodapé, geralmente para totais).

Mesclando Células

Sabe quando você precisa que uma célula ocupe mais espaço? Temos atributos para isso!

  • colspan="2": Expande a célula horizontalmente (ocupa colunas adjacentes).
  • rowspan="2": Expande a célula verticalmente (ocupa linhas adjacentes).

Nota: Estilização com bgcolor ou cellpadding ficou no passado! Agora é tudo feito com CSS limpo.
