🏗️ Introdução ao HTML na Prática

Aqui o negócio começou a ficar sério! Resumo de como estruturar a "ossatura" de qualquer página web.

A Estrutura de Milhões

Todo documento HTML5 começa com a declaração <!DOCTYPE html> para avisar o navegador qual é a versão. Depois, temos duas áreas vitais:

  • HEAD: A "cabeça". Onde ficam as configurações, links de CSS, título da aba do navegador e metadados. O usuário não vê o que está aqui (salvo o título).
  • BODY: O "corpo". É aqui que a mágica acontece. Tudo o que é visual no navegador (textos, imagens, botões) fica dentro desta tag.

🔍 O Inspetor de Elementos

Descobri que a tecla F12 (ou Botão Direito > Inspecionar) é a melhor amiga do Front-End. O DevTools do navegador permite fuçar o código HTML e CSS de qualquer site e testar alterações em tempo real!

Atributos: O poder extra das Tags

As tags podem ter atributos que dão a elas características específicas. Por exemplo, a tag de link <a> precisa do atributo href="url" para saber para onde direcionar o clique. E para abrir em nova aba? Usamos o atributo target="_blank"!
