## 💡 Aprendizados e Observações

Neste desafio, pude rever conceitos fundamentais sobre a Web:
- **Estrutura Cliente x Servidor:** Compreendi o papel do navegador (*Client*) ao interpretar o HTML enviado pelo servidor (*Server*).
- **Navegação Inteligente:** Criação de um menu de índice funcional no topo da página e páginas interligadas (arquivos HTML locais), garantindo uma navegação fluida pelo conteúdo.
- **Tags Depreciadas vs. Boas Práticas:** Compreensão sobre a tag `<font>` (utilizada apenas para fins do desafio) e a importância absoluta da separação de responsabilidades entre HTML (estrutura/semântica) e CSS (estilização).

## 🛠️ Tags e Recursos Utilizados

Durante o desenvolvimento, foram aplicadas as seguintes estruturas HTML5:

- **Cabeçalhos e Divisores:** `<h1>` até `<h6>`, `<hr>`
- **Parágrafos e Formatação de Texto:** `<p>`, `<strong>`, `<i>`, `<u>`, `<mark>`, `<small>`, `<sub>`, `<sup>`, `<del>`, `<font>`
- **Citações e Abreviações:** `<blockquote>`, `<abbr>`
- **Listas:** Ordenadas (`<ol>`) e Não Ordenadas (`<ul>`) com itens (`<li>`)
- **Navegação e Hiperlinks:** `<a>` (com navegação entre arquivos `.html`, navegação interna via `id` e links externos abrindo em nova guia com `target="_blank"`)
- **Controle de Versão:** Git e GitHub para documentação e versionamento.
