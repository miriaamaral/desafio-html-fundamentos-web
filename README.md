# Desafio de Código Santander: Revendo os Primeiros Passos com HTML 🌐

E aí, meu 🐙! Sinta-se em casa. Este é a mais um repositório onde coloco em teste minha mémória e conhecimentos como Desenvolvedora Front-End! 

Este projeto contém a resolução do desafio prático do **Módulo 1 - Primeiros Passos com HTML**, oferecido pela [Digital Innovation One (DIO)](https://dio.me) em parceria com o **Santander Bootcamp 2025 - Front-End**. ## 💡 Aprendizados e Destaques

Neste desafio, pude rever conceitos fundamentais sobre a Web:

* **Estrutura Client x Server:** Compreender o papel do navegador (*client*) ao interpretar o HTML enviado pelo servidor.
* **Navegação por Âncoras:** Criação de um menu de índice funcional no topo da página com botões de "Voltar ao índice", garantindo uma navegação fluida pelo conteúdo.
* **Tags Depreciadas vs. Boas Práticas:** Compreensão sobre a tag `<font>` (utilizada para fins do desafio) e a importância da separação de responsabilidades entre HTML (estrutura) e CSS (estilo).

---

## 🛠️ Tags e Recursos Utilizados

Durante o desenvolvimento, foram aplicadas as seguintes tags e estruturas HTML:

* **HTML5:** Estrutura base de toda a página.
* **Cabeçalhos e Divisores:** `<h1>` até `<h6>`, `<hr>`.
* **Parágrafos e Formatação de Texto:** `<p>`, `<strong>`, `<i>`, `<u>`, `<mark>`, `<small>`, `<sub>`, `<sup>`, `<del>`, `<font>`.
* **Citações e Abreviações:** `<blockquote>`, `<abbr>`.
* **Listas:** Ordenadas (`<ol>`) e Não Ordenadas (`<ul>`) com itens (`<li>`).
* **Navegação e Âncoras:** `<a>` (com navegação interna via `id` e links externos abrindo em nova guia com `target="_blank"`).
* **Git & GitHub:** Versionamento de código e documentação.
