Entendendo Comunicação Client x Server

O que é o Client?

O Client (Cliente) é o navegador do usuário, responsável por solicitar arquivos e processar o HTML, CSS e JavaScript para exibir a interface gráfica.

O que é o Server?

O Server (Servidor) é a máquina onde o site e o banco de dados estão hospedados. Ele recebe a requisição do cliente e devolve os arquivos necessários.
