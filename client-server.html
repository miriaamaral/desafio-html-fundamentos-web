🌐 Entendendo Comunicação Client x Server

E aí, meu 🐙! Bem-vindos a mais uma página do meu caderno digital. Aqui, o foco é a base de tudo: como a internet conversa!

O que é o Client (Cliente)?

O Client é basicamente quem pede a informação. No nosso dia a dia, é o navegador do usuário (Chrome, Edge, Firefox). Ele é responsável por solicitar arquivos e processar o HTML, CSS e JavaScript para renderizar aquela interface visual bonita que nós, devs Front-End, construímos.

O que é o Server (Servidor)?

O Server é a "fonte". É a máquina (computador superpotente) onde o site e o banco de dados estão hospedados. Ele recebe a requisição do Client, processa a lógica de back-end e devolve a resposta com os arquivos necessários.

⚠️ Polêmica Rápida: HTML é linguagem de programação?

Sim, com certeza. NÃO! Aprendi na aula que HTML é uma Linguagem de Marcação. Ele não tem lógica (como if/else), serve apenas para estruturar textos através de tags que o navegador consegue interpretar.
