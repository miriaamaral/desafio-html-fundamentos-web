📝 Trabalhando com Formulários em HTML

Fala, dev! Se não fosse o formulário, como a gente faria login nas redes sociais ou compraria na internet? Esta aula foi fundamental!

A Tag Mãe: <form>

Toda a área de preenchimento de dados deve ficar dentro da tag <form>. É ela que avisa ao navegador que aqueles dados serão agrupados e enviados para algum lugar (para o nosso Server, por exemplo).

O versátil <input>

A tag mais usada em formulários não precisa ser "fechada" e muda de rosto dependendo do atributo type. Meus favoritos são:

  • type="text": Para textos simples (como nomes).
  • type="password": Esconde os caracteres (famosas bolinhas).
  • type="radio": Múltipla escolha onde só se pode selecionar uma opção.
  • type="checkbox": Caixinha de seleção (pode marcar várias).
  • type="submit": O famoso botão mágico de enviar!

A importância do <label>

Acessibilidade é tudo! A tag <label> serve para nomear os campos de texto. Quando linkamos ela ao input através do atributo for="id-do-input", o usuário pode clicar no texto para ativar o campo. Leitores de tela também agradecem!
