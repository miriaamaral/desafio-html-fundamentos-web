🐙 Git e GitHub: Primeiros Passos

Fala, dev! Chegou a hora de falar sobre as ferramentas que salvam as nossas vidas (e nossos códigos). Minhas anotações da aula da Elidiana!

Git ≠ GitHub (Parecem iguais, mas não são!)

  • Git: É o sistema de versionamento de código que roda localmente na nossa máquina. Ele tira "fotos" (snapshots) do projeto e permite voltar no tempo ou criar ramificações (branches) sem quebrar o código principal.
  • GitHub: É a plataforma em nuvem (rede social de devs) onde hospedamos nossos repositórios Git, facilitando o trabalho em equipe e servindo como nosso Portfólio!

🛠️ Comandos que já decorei:

  1. git init: Inicia o "poder do Git" em uma pasta local.
  2. git clone: Copia um repositório da nuvem para o meu PC.
  3. git add .: Manda os arquivos modificados para a Staging Area (Área de preparação).
  4. git commit -m "...": Salva as alterações com uma mensagem descritiva (a "foto" do momento).
  5. git push origin main: Empurra o código do meu PC lá para o GitHub!
"A prática leva à perfeição... e a muitos conflitos de merge também, mas a gente resolve!"
